# 六页面设计稿改造验证（2026-10-28）

依据用户指定的 codex-clipboard-6a685b84-9651-479a-8de1-303271393466.png，调整首页、视频库、播放器、每日课程、设置、百度授权页面。暖白背景、深绿主色、字体、页边距、列表和底部导航使用统一样式。

## 本轮变化

- 首页使用横幅续播卡和紧凑历史列表；视频库使用双列视频和下划线标签。
- 每日课程使用名称输入、来源切换和缩略图选集；文件夹选择后折叠，手选顺序按需展开。
- 设置使用六个平面菜单行，原有设置内容按需展开。
- 授权页保留状态、云图标、显式授权按钮和真实隐私说明。
- 播放器使用全屏舞台和完整比例媒体；H5 自定义控制、Android 原生覆盖控制分别实现。

## 验证证据

- 全量检查：类型检查、657 项测试、H5 构建、敏感信息扫描。
- 移动端 Playwright：10 项通过；文件夹选课与手选模式额外人工检查。
- H5 实播：本地 65 秒测试视频可播放、前进 15 秒、暂停。
- App 资源编译与 git diff --check 单独验证。
- 六页预览：`../../output/design-validation/pages-review.png`。
- 文件夹模式：`../../output/daily-folder-review.png`。

## 验证范围

预览使用 390×620 H5 视口、开发 mock 数据；测试媒体仅用于验证播放器控制。视频名称、封面、数量、账号状态和缓存统计使用实际数据，因而不会固定为设计稿示例。云图标为 CSS 绘制，品牌使用项目已有素材，不能据此宣称逐像素一致。

本轮尚未验证 Android 真机上的覆盖控制、安全区和真实百度原文件播放；App 资源编译不等于 APK。此前 1.0.8 APK 不包含本轮修改，本轮未生成新 APK。
