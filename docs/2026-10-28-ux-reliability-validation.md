# 学习体验与可靠性验证

日期：2026-10-28。范围：不依赖安卓真机的五项优化。

## 已实现与验证

- 大列表：课程每批20门，课程集数、选择视频及重新关联候选每批50条；默认不渲染收起的集数。首页补学每批20条。组件测试覆盖60门课程各200集、2000条视频，验证首次渲染数量、继续显示和搜索末尾数据。
- 播放错误：区分明确的网络、HTTP404、访问拒绝与未知错误；不从URL中的字样猜测错误，不把一般解码失败说成链接过期。提供重试、授权或来源检查入口。
- 备份：明确区分文本生成、复制成功、浏览器发起下载、安卓文件写入并读回校验成功；分别保存最近操作时间。浏览器无法确认用户最终保存文件，因此不报告“已保存”。
- 窄屏：320px视口及注入22px字体，检查长课程名、课程操作、备份恢复确认框和播放器错误操作；发现并修复创建课程按钮不足44px的问题。无横向溢出或相关JavaScript异常。
- 存储：恢复、重新关联等多项写入前保存恢复记录，下次启动先恢复未完成操作；空间不足时不覆盖未恢复数据，提供重试。恢复后继续加载登录与视频来源。播放进度保存失败不会中断播放或误记成功，可重试。

## 测试证据

- `npm run check`：742项测试通过，类型检查、H5构建和凭证模式扫描通过。
- `tests/e2e/ux-reliability.spec.ts`：2项移动尺寸浏览器测试通过（窄屏字体模拟、明确404错误）。
- 文件恢复故障测试覆盖：写入部分数据后中断、日志写入失败、回退失败后重试、启动读取顺序，以及未恢复时禁止修改数据。
- 本轮浏览器截图位于 `test-results/`，后续浏览器测试可能覆盖该目录。

## 验证边界

没有连接安卓真机。浏览器字体注入不等同于安卓系统大字体；网络与媒体错误使用模拟响应／事件。锁屏、来电、后台长期播放、真实视频解码和安卓实际文件转存仍待真机验证。本轮源代码构建不代表生成了新的APK。
