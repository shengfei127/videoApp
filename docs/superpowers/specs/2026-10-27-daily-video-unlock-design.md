# 首页已看记录与每日课程解锁设计

- 日期：2026-10-27
- 状态：设计稿待用户评审
- 平台：Android App；H5 用于自动化验证
- 技术栈：uni-app、Vue 3、TypeScript、Pinia、本机存储

## 1. 目标

1. 首页“最近视频”只展示本机播放历史中出现、且当前仍存在于视频库的视频，并按最近播放时间倒序排列。
2. 提供可选的每日课程解锁：用户可把视频文件夹或手选视频组成一门课程；开启总开关后，每门课程按自然日每天增加一集可播放内容。
3. 解锁规则完全本地运行，支持离线浏览与播放，不新增账号、后端或百度接口依赖。

## 2. 已确认的产品规则

### 2.1 首页最近视频

- 以现有 `PlaybackProgress.updatedAt` 播放记录作为“看过”的依据；存在记录即算看过，不要求达到 30 秒，也包括已播放完成的视频。
- 只展示同时存在于当前合并视频库中的记录。百度缓存暂时没有某条记录对应的视频时先不展示；记录保留，视频再次同步出现后可重新显示。
- 按 `updatedAt` 从新到旧排序，同一视频只显示一次。首页最多展示 6 条；无匹配记录时显示空状态。
- 视频库现有“最近视频”列表继续表示整个可浏览目录，不改变其搜索和排序语义。

### 2.2 每日解锁开关与课程

- 设置页新增全局开关“每日解锁课程”，默认关闭。关闭时所有视频均可播放；课程清单和创建日期保留，开关重新打开后按当前日期重新计算进度。
- 设置页提供课程管理入口，可查看课程名称、已解锁/总集数、下一集解锁时间，并创建或删除课程。
- 一门课程可由以下任一方式创建：
  1. 选择视频库中的文件夹，创建时把该文件夹及其子文件夹内当时存在的视频作为课程快照。
  2. 从当前视频库多选视频，形成自定义课程；百度视频和已导入直链均可选。
- 创建后课程集数固定。后续同步中新出现的视频不会自动插入；目录中已有视频被删除或暂时不可用时，其课程位置保留，不会让后续集数提前解锁。
- 同一视频不能同时加入多门课程，避免重复归属导致解锁时间不明确。冲突时提示课程名称，用户需先移除旧课程再创建新课程。
- 文件夹课程与自选课程均按视频名称使用中文自然排序（例如第2集排在第10集之前）；名称相同时按完整路径、视频 ID 稳定排序。课程创建后不因网盘重新排序而改变。
- 新课程创建当天立即解锁第1集；每经过一个本机自然日，在本机 00:00 解锁下一集。未观看的解锁会累积，不因错过某一天而丢失。公式为 `min(课程总集数, 自然日差 + 1)`。
- 自然日采用设备当前本地时区的年月日边界，不用固定 24 小时滚动窗口；夏令时变化仍以本地日历日计算。
- 解锁是“可播放集数”逐日累加，不会限制已解锁集数的重复观看。全局开关关闭时暂时跳过限制。

### 2.3 浏览与播放拦截

- 视频库仍展示课程全部视频，并标记已解锁或待解锁状态；锁定视频显示“第 N 集，YYYY-MM-DD 00:00 解锁”。
- 点击锁定视频时显示解锁时间，不发起播放地址解析，也不消耗解锁名额。
- 播放器在处理页面参数、解析百度地址或直链之前再次检查访问权限，阻止通过深链绕开页面提示。到达本机零点或 App 从后台恢复时重新计算状态。
- 删除课程后，课程不再限制其中的视频；播放历史、续播进度和目录缓存不受影响。重新建课视为新课程并从新建当天开始计算。

## 3. 数据模型与持久化

新增版本化本机存储键 `pianke:daily-unlock:v1`，保存全局开关和课程快照。建议领域结构：

```ts
interface DailyUnlockSettings {
  enabled: boolean
  courses: DailyUnlockCourse[]
}

interface DailyUnlockCourse {
  id: string
  name: string
  createdAt: number
  sourceFolderPath?: string
  episodes: Array<{
    videoId: string
    name: string
    path: string
  }>
}
```

存储读取需校验结构、字段长度、重复 ID 与上限；无效记录安全忽略或回退到默认关闭、空课程，不影响授权、目录、直链和播放历史。所有配置只保存在本机，不记录百度访问凭证或临时播放地址。

每日开放集数通过 `createdAt` 的本地日历日期和当前本地日期即时推导，不维护易过期的“今日计数器”，也不需要网络定时任务。应用不能对抗用户修改设备时钟；这项功能定位为本机自我管理，而非服务端防作弊或付费 DRM。

## 4. 页面与模块职责

| 区域 | 职责 |
| --- | --- |
| 首页 | 用播放历史生成最近播放视频列表 |
| 设置页 | 全局开关、课程管理入口与课程状态 |
| 课程管理/选择界面 | 浏览目录、选择文件夹或多选视频、创建及删除课程 |
| 视频库 | 显示课程锁定状态，并在播放前给出解锁提示 |
| 播放器 | 在解析媒体地址前执行最终授权检查，并显示可理解的锁定状态 |
| `DailyUnlockRepository` | 校验并读写每日解锁设置和课程快照 |
| 领域策略 | 自然日计算、稳定集数排序、课程冲突检测和视频可播放判定 |

播放器权限策略必须由可单测的领域模块提供，页面和 store 共用同一判定，避免显示状态与实际播放入口不一致。存储写入失败时不更新已确认的界面状态，并提示保存失败。

## 5. 状态刷新与时区边界

- 页面首次显示、App 从后台返回、课程开关/配置改变以及下一次本地零点都触发解锁状态重新计算。
- 课程进度展示按当前本地日期生成；若运行中跨过午夜，状态应在零点后更新，不要求用户强制退出重开。
- 用户修改系统时区后，以新时区当前本地日期重新计算自然日差。该行为符合本机“自然日”规则，也意味着解锁不是可信的服务端时间证明。

## 6. 验收标准

1. 没有任何播放进度的目录视频不出现在首页最近视频；播放过的视频按最近更新时间排序，完成视频保留，目录中暂时缺失的视频隐藏。
2. 全局开关关闭时播放器无额外阻拦；开启时课程第1集立即可看，第2集在创建次日 00:00 可看，连续跨日后未观看的集数累积开放。
3. 时间测试覆盖本地午夜、月末/年末和夏令时边界，并使用注入时钟避免真实等待。
4. 直接打开被锁定视频的播放器路由不会触发百度地址解析或直链加载；零点后无需重建课程即可播放刚解锁集数。
5. 文件夹快照、子文件夹、中文数字自然排序、相同名称稳定排序、目录视频缺失、课程冲突、删除课程和损坏存储均有测试。
6. 播放记录清理和目录缓存清理不误删每日解锁配置；关闭/重新开启开关不丢课程。
7. Android 兼容当前 App WebView；H5 单元与端到端测试、类型检查、App 编译通过。

## 7. 明确不做

- 不增加账号同步、云端课程、跨设备进度或后端强制解锁。
- 不把未解锁视频从目录中隐藏，也不改变百度授权和视频播放协议。
- 不把“每天一集”实现成每日仅一次播放；一旦解锁，该集可重复观看。
- 不在本功能中改变视频库原有的完整最近列表、搜索或文件夹导航。
